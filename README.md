# Side Hero Entertainment 🎬

> A state-of-the-art cinematic web experience built for **Side Hero Entertainment Pvt. Ltd.** (`www.sideheroentertainment.com`), crafted with the luxury, dark-aesthetic, and high-performance craftsmanship inspired by **DG Cinema** (`www.dg-cinema.com/en`).

---

## 🌟 Overview & Creative Inspiration

This project reimagines the digital presence of **Side Hero Entertainment**, moving from a traditional WordPress site to an ultra-modern, cinematic, and responsive web experience.

Taking direct inspiration from [DG Cinema](https://www.dg-cinema.com/en), this website incorporates:
- **Curved Anamorphic Screen Viewport**: Signature elliptical top and bottom masks simulating an anamorphic widescreen lens perspective.
- **Continuous Infinite Marquee Film Reel**: Linear smooth-scrolling film reel showcasing real posters and production stills.
- **Dynamic Preloader Screen**: 0%–100% digital ease counter, shutter curtain wipe animations, and red recording indicator.
- **Camera Viewfinder HUD Aesthetics**: Framing crosshair corner brackets, exposure ruler (`3 . . 2 . . 1 . . 0 . . 1 . . 2 . . 3`), and live real-time studio clock (IST Mumbai).
- **3D Layered Perspective Fan Cards**: Signature depth-stacked cards spotlighting flagship productions like *No Land's Man*.
- **Interactive Project & Bio Dossier Modals**: Complete modal popups with loglines, synopses, cast, crew, and technical metadata.
- **Filterable Production Portfolio**: Real-time category filtering across Feature Films, Documentaries, Music Singles, and Commercial Ads.
- **Typographic Visionaries Ribbon**: Bold editorial marquee with integrated inline photographic cutouts.
- **Dark Luxury Palette**: Deep obsidian (`#09080A`), metallic silver text gradients, subtle borders, and crimson red accents (`#E50913`).

## 🚀 Quick Start & Development

The website is engineered with zero dependency requirements to run. You can simply double-click `index.html` in any browser, or use local development servers:

### Option A: Direct Browser Preview
Double-click `index.html` or open it with your favorite browser (Chrome, Edge, Safari, Firefox).

### Option B: Local Development Server
```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .

# Using Vite
npm install
npm run dev
```

## 🚢 GitHub Pages Deployment

This repository includes a pre-configured GitHub Actions workflow in `.github/workflows/deploy.yml`.
When you push to the `main` branch:
1. Navigate to your repository settings: **Settings > Pages**.
2. Under **Build and deployment > Source**, select **GitHub Actions**.
3. Your site will automatically build and publish live to GitHub Pages.
